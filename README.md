# Encriptador de Texto

Aplicación web desarrollada como parte del programa Oracle Next Education de Alura Latam.

Permite ingresar un texto para encriptarlo y posteriormente desencriptarlo utilizando reglas de sustitución de caracteres.

## Funcionalidades

- Encriptar texto.
- Desencriptar texto.
- Copiar el resultado.
- Validar el texto ingresado.
- Interfaz web adaptable.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Reglas de encriptación

Las vocales se reemplazan de la siguiente manera:

- `a` se convierte en `ai`
- `e` se convierte en `enter`
- `i` se convierte en `imes`
- `o` se convierte en `ober`
- `u` se convierte en `ufat`
